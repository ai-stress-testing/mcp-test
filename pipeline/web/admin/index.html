Pricing experiment

Each row is one price point tested in a region. A region is only marked Trending once it clears the minimum-sample gate (50 conversions, same gate the pricing engine uses) -- below that it reads Gathering data, never a winner. This view does not duplicate the pricing engine's statistical-significance test, so it never labels an arm “winner”; a decisive-winner read requires that computation and is a data- contract gap flagged to backend-dev (design spec §9).
